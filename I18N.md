# Internationalization (i18n) Guide

This document explains how Eco Natural's multilingual support works and how to maintain or extend it.

## Overview

Eco Natural supports **three languages:**
- English (en) — Default, at root `/`
- Turkish (tr) — At `/tr/`
- Russian (ru) — At `/ru/`

All three languages share:
- Same product slugs and URLs (only locale prefix differs)
- Same images and styling
- Separate translations for UI strings and product content

## Architecture

### Three Layers of Translation

#### Layer 1: UI Strings (44 keys)

**Files:** `locales/{en|tr|ru}.json`

These are hardcoded UI elements like navigation buttons, section headings, CTAs:

```json
{
  "back_link": "← All Products",
  "order_via_whatsapp": "Order via WhatsApp",
  "origin_story_eyebrow": "Origin & Story",
  "categories": {
    "Specialty Oils": "Specialty Oils",
    "Condiments & Extracts": "Condiments & Extracts"
  }
}
```

**Usage in templates:**
```python
ctx.t("back_link")              # Returns translated string
ctx.t("wa_message", product_name="Hemp Oil")  # Format with variables
```

#### Layer 2: Product Enrichment (29 products)

**Files:** `src/enrichment.py` (English), `locales/enrichment_{tr|ru}.py`

Rich product content with stories, taglines, feature badges:

```python
"EN-HEMP-SEED-OIL-250ML": {
    "origin_place": "Turkey",
    "story": [
        "Hemp seed has been cultivated in Anatolia...",
        "Light on the palate, versatile in the kitchen..."
    ],
    "how_to_use": [
        ("🥗", "Salads & Bowls"),
        ("🫙", "Finishing Drizzle"),
        # ... 4 more
    ],
    "badges": [
        ("❄️", "Cold Pressed", "No heat — full nutrition preserved"),
        # ... 4 more
    ],
    "product_line": "Eco Natural Specialty Oils · 250 ml",
    "tagline": "Cold pressed from whole hemp seeds...",
    "is_gift": False,  # Non-translatable
}
```

**How it works:**
- English enrichment is in `src/enrichment.py` (canonical source)
- Turkish enrichment in `locales/enrichment_tr.py` (overrides English for TR locale)
- Russian enrichment in `locales/enrichment_ru.py` (overrides English for RU locale)
- During generation, English values are merged with locale overrides (so untranslated fields fall back to English)

#### Layer 3: CSV Metadata (29 products)

**Files:** `data/{ids|ids_tr|ids_ru}.csv`

Product metadata read from CSV:

```csv
filename,product_id,page_title,slug,short_description,full_description,seo_title,meta_description
BRD_5999.JPG,EN-HEMP-SEED-OIL-250ML,"Eco Natural Hemp Seed Oil – 250 ml","eco-natural-hemp-seed-oil-250ml","A smooth, plant-based oil...","Eco Natural Hemp Seed Oil is a premium...",
```

**Translatable columns:**
- `page_title` — Product name on page
- `short_description` — One-liner
- `full_description` — Detailed copy
- `seo_title` — `<title>` tag content
- `meta_description` — Meta tag content

**Non-translatable columns:**
- `filename` — Image filename (same across locales)
- `product_id` — Product ID (EN-HEMP-SEED-OIL-250ML, etc.)
- `slug` — URL slug (same across locales, allowing simple cross-language navigation)

## Generation Flow

```
generator loop (for each locale: en, tr, ru)
  ├─ Load locale strings: locales/{locale}.json
  ├─ Load locale enrichment: enrichment_{locale}.py (or English fallback)
  ├─ Load locale CSV: data/ids_{locale}.csv (or ids.csv for en)
  ├─ Create Ctx object:
  │   Ctx(locale=locale, strings=strings, enrichment=enrichment, is_subdir=(locale != "en"))
  │
  ├─ For each product row:
  │   ├─ Merge enrichment: {**ENGLISH, **locale_enrichment}
  │   └─ Render page_template(..., ctx) → Write to output_dir/{slug}.html
  │
  └─ Render index_template(..., ctx) → Write index.html
```

### Ctx Object

All templates receive a `Ctx` (context) object that provides translations and locale metadata:

```python
@dataclass
class Ctx:
    locale: str         # "en", "tr", or "ru"
    strings: dict       # Loaded from locales/{locale}.json
    enrichment: dict    # Locale-specific product content
    is_subdir: bool     # True for tr, ru (page is in subdirectory)
    
    def t(self, key: str, **fmt) -> str:
        """Translate UI string with optional .format() substitutions."""
        val = self.strings.get(key, f"[MISSING:{key}]")
        return val.format(**fmt) if fmt else val
    
    def asset_prefix(self) -> str:
        """Return path prefix: "./" for root en, "../" for subdirs tr/ru."""
        return "../" if self.is_subdir else "./"
    
    def cat_name(self, cat: str) -> str:
        """Get translated category name."""
        return self.strings.get("categories", {}).get(cat, cat)
```

## Translation Workflow

### Translating UI Strings

1. **Edit `locales/en.json`** (master language):
   ```json
   {
     "new_button": "Click Me"
   }
   ```

2. **Sync to Turkish and Russian**:
   ```bash
   # Copy the key to tr.json and ru.json with translated values
   ```

   **`locales/tr.json`:**
   ```json
   {
     "new_button": "Bana Tıkla"
   }
   ```

   **`locales/ru.json`:**
   ```json
   {
     "new_button": "Нажми на меня"
   }
   ```

3. **Update template** to use the new string:
   ```python
   ctx.t("new_button")  # Returns translated button text
   ```

4. **Regenerate**:
   ```bash
   python3 src/generate.py
   ```

### Translating a Product

#### Scenario: Update a product's story

1. **Edit English source** (`src/enrichment.py`):
   ```python
   "EN-HEMP-SEED-OIL-250ML": {
       "story": [
           "Updated paragraph 1...",
           "Updated paragraph 2..."
       ]
   }
   ```

2. **Update Turkish version** (`locales/enrichment_tr.py`):
   ```python
   "EN-HEMP-SEED-OIL-250ML": {
       "story": [
           "Güncellenmiş paragraf 1...",
           "Güncellenmiş paragraf 2..."
       ]
   }
   ```

3. **Update Russian version** (`locales/enrichment_ru.py`):
   ```python
   "EN-HEMP-SEED-OIL-250ML": {
       "story": [
           "Обновленный абзац 1...",
           "Обновленный абзац 2..."
       ]
   }
   ```

4. **Regenerate**:
   ```bash
   python3 src/generate.py
   ```

#### Scenario: Update product CSV metadata

1. **Edit English CSV** (`data/ids.csv`), e.g., row for hemp oil:
   ```csv
   BRD_5999.JPG,EN-HEMP-SEED-OIL-250ML,"Updated Title","eco-natural-hemp-seed-oil-250ml","Updated short desc","Updated full desc",...
   ```

2. **Update Turkish CSV** (`data/ids_tr.csv`) with same product_id and slug, translated titles/descriptions:
   ```csv
   BRD_5999.JPG,EN-HEMP-SEED-OIL-250ML,"Güncellenmiş Başlık","eco-natural-hemp-seed-oil-250ml","Güncellenmiş kısa açıkl","Güncellenmiş açıkl",...
   ```

3. **Update Russian CSV** (`data/ids_ru.csv`):
   ```csv
   BRD_5999.JPG,EN-HEMP-SEED-OIL-250ML,"Обновленный заголовок","eco-natural-hemp-seed-oil-250ml","Обновленное краткое описание","Обновленное описание",...
   ```

4. **Regenerate**:
   ```bash
   python3 src/generate.py
   ```

### Adding a New Language

To add a fourth language (e.g., German "de"):

1. **Create locale JSON** (`locales/de.json`):
   ```json
   {
     "back_link": "← Alle Produkte",
     "order_via_whatsapp": "Über WhatsApp bestellen",
     // ... all 44 keys
     "categories": {
       "Specialty Oils": "Spezielle Öle",
       // ... all 8 categories
     }
   }
   ```

2. **Create enrichment file** (`locales/enrichment_de.py`):
   ```python
   ENRICHMENT_DE: dict[str, dict] = {
       "EN-HEMP-SEED-OIL-250ML": {
           "origin_place": "Türkei",
           "story": ["...", "..."],
           # ... all fields
       },
       # ... all 29 products
   }
   ```

3. **Create CSV** (`data/ids_de.csv`):
   ```csv
   # Copy ids.csv and translate columns 3–8
   ```

4. **Update generator** (`src/generate.py`):
   ```python
   LOCALES = [
       ("en", ROOT,         ROOT / "data" / "ids.csv"),
       ("tr", ROOT / "tr",  ROOT / "data" / "ids_tr.csv"),
       ("ru", ROOT / "ru",  ROOT / "data" / "ids_ru.csv"),
       ("de", ROOT / "de",  ROOT / "data" / "ids_de.csv"),  # Add this
   ]
   ```

5. **Regenerate**:
   ```bash
   python3 src/generate.py
   ```

Output: `/de/index.html` and `/de/[product-slug].html` pages in German.

## URL Structure

All locales share identical product slugs — only the directory prefix changes:

```
en: /index.html
tr: /tr/index.html
ru: /ru/index.html

en: /eco-natural-hemp-seed-oil-250ml.html
tr: /tr/eco-natural-hemp-seed-oil-250ml.html
ru: /ru/eco-natural-hemp-seed-oil-250ml.html
```

This makes **cross-language navigation trivial** — replace the leading path segment.

### Language Switcher

The topbar includes a language switcher that generates links to the equivalent page in other languages:

```html
<div class="lang-switcher">
  <a href="/index.html" class="lang-item lang-item--active">EN</a>
  <a href="/tr/index.html" class="lang-item">TR</a>
  <a href="/ru/index.html" class="lang-item">RU</a>
</div>
```

The switcher URL logic:
- **From en locale:** `/path.html`, `/tr/path.html`, `/ru/path.html`
- **From tr locale:** `../path.html`, `path.html`, `../ru/path.html`
- **From ru locale:** `../path.html`, `../tr/path.html`, `path.html`

## Quality Assurance

### Translation Completeness

All three translations must be kept in sync:

- **JSON strings:** Same 44 keys in `en.json`, `tr.json`, `ru.json`
- **Enrichment:** Same 29 product IDs in `enrichment.py`, `enrichment_tr.py`, `enrichment_ru.py`
- **CSV:** Same product rows across `ids.csv`, `ids_tr.csv`, `ids_ru.csv`

Missing translations will show as blank or fall back to English.

### Verification

After making translation changes:

```bash
# Regenerate all pages
python3 src/generate.py

# Check that all locales were generated
ls -1 *.html | wc -l  # Should be 29 (index + 28 products)
ls -1 tr/*.html | wc -l  # Should be 29
ls -1 ru/*.html | wc -l  # Should be 29

# Verify a specific translation appears
grep "Dünyanın Kalıcı Tadı" tr/index.html  # Turkish tagline
grep "Постоянный вкус земли" ru/index.html  # Russian tagline

# Commit
git add -A
git commit -m "Update translations for [feature]"
git push
```

## Common Issues

### Translation Missing or Showing as `[MISSING:key]`

**Cause:** The key doesn't exist in the locale JSON file.

**Fix:** Add the key to all three locale JSON files:
```json
"missing_key": "English text here"  // en.json
"missing_key": "Turkish text here"  // tr.json
"missing_key": "Russian text here"  // ru.json
```

### Product Shows English Content in Turkish/Russian

**Cause:** The product entry doesn't exist in the locale enrichment file or CSV.

**Fix:** Add the product to `locales/enrichment_tr.py`, `enrichment_ru.py`, and `data/ids_tr.csv`, `ids_ru.csv`.

### Path Issues (404 on images in subdirectories)

**Cause:** Assets not properly localized with `../` prefix.

**Fix:** All asset paths must use `_localize_path(path, ctx)` in templates. This is already implemented; if you're seeing 404s, check that generated HTML uses `../img/...` and `../style.css` in `/tr/` and `/ru/` pages.

### Inconsistent Slugs Across Locales

**Cause:** Slugs should be identical but were translated.

**Fix:** Slugs must be **identical** across all locales. Only translate the `page_title`, descriptions, and taglines. The `slug` column in CSV should be the same in all three locale files.

## Performance Impact

Multilingual support has **zero runtime overhead**:

- **No JavaScript** required for language switching
- **No server-side logic** — all translations baked into static HTML
- **Minimal file size increase** — 87 total pages (29 × 3 locales + 1 shared CSS) vs. 29 pages if English-only
- **CDN-friendly** — each locale is a separate directory tree

## SEO Considerations

### hreflang Tags

Each page declares language alternates for search engines:

```html
<link rel="alternate" hreflang="en" href="https://example.com/product.html">
<link rel="alternate" hreflang="tr" href="https://example.com/tr/product.html">
<link rel="alternate" hreflang="ru" href="https://example.com/ru/product.html">
<link rel="alternate" hreflang="x-default" href="https://example.com/product.html">
```

This tells Google that these are the same content in different languages.

### Lang Attribute

Each page's `<html>` tag declares its language:

```html
<html lang="en">  <!-- English -->
<html lang="tr">  <!-- Turkish -->
<html lang="ru">  <!-- Russian -->
```
